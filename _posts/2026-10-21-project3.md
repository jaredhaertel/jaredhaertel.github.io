In Part A, we use the pretrained flow model PixNerd to explore denoising, velocity, Euler sampling, and classifier-free guidance along with some neat applications to editing, visual anagrams, and hybrid images. In Part B, we build a UNet from scratch and train it on MNIST to generate digits.

Throughout this project I use the linear flow-matching convention $$x_t = (1-t)\epsilon + t x_1$$ with $$\epsilon \sim \mathcal{N}(0, I)$$, so time 0 is pure noise and time 1 is a clean image.

# Part A: Exploring the Power of Flow Models

All Part A runs use the pretrained PixNerd-XXL-P16-T2I model at 512×512, seed 180, Euler step size $$h = 0.02$$, and CFG weight $$w = 7$$.

### Part 1.3: One-Step Denoising

The model predicts a velocity $$v_\theta(x_t, t, c)$$, not noise as is done in diffusion. Since the velocity along the linear path is constant, one step of size $$1 - t$$ jumps straight to an estimate of the clean image: $$\hat{x}_1 = x_t + (1-t)\, v_\theta(x_t, t, c)$$. Note that the velocity in some sense points to the center of the distribution of reasonable images conditioned on $x_t$, and so for low $t$ we get very smooth images with little high frequency detail. Here, I condition on the prompt "a high quality photo".

### Part 1.5: Iterative Denoising with Euler Sampling

We can think of the velocity as we do in physics, and likewise we can integrate along this velocity to generate a trajectory to the image manifold. We do this via Euler sampling with $$x_{t+h} = x_t + h\, v_\theta(x_t, t, c)$$, and recompute the velocity after each step. The last step is shortened so it ends exactly at $$t = 1$$. I tested the sampler on a constant velocity field (50 steps from 0, 25 from 0.5, and 4 from 0.93 with a shortened final step), and all checks passed.

Starting from the saved $$t = 0.50$$ input, I run 25 Euler updates with $$h = 0.02$$.

## Part 2: Conditional Generation and Guidance

### Part 2.1: Classifier-Free Guidance

Classifier-free guidance pushes the conditional velocity further away from the unconditional one by running the model twice: $$v_{\text{cfg}} = v_c + w(v_c - v_u)$$, where $$v_u$$ uses the empty prompt. Both branches use the same $$x_t$$ and $$t$$, and $$w = 0$$ gives back the plain conditional prediction. These samples use the same initial noise as Section 1.6, with $$w = 7$$.

### Part 3.3: Visual Anagrams

A visual anagram looks like one prompt upright and another when rotated 180°. At each step I average the CFG velocity for prompt A with the rotated-back CFG velocity for prompt B evaluated on the rotated image, which is encoded in the formula $$v = \tfrac{1}{2}\big(v_{\text{cfg}}(x_t, t, c_a) + F(v_{\text{cfg}}(F(x_t), t, c_b))\big)$$. $$F$$ can be any invertible symmetry that preserves noise statistics. In this case, it simply flips both spatial axes.

### Part 3.4: Hybrid Images

Following factorized diffusion, I combine the low frequencies of one prompt's velocity with the high frequencies of another's: $$v = f_{\text{lowpass}}(v_a) + f_{\text{highpass}}(v_b)$$. The low pass is a Gaussian blur with kernel size 265 and σ = 16, and the high pass is the velocity minus its low pass. Prompt A sets what you see from far away, and prompt B sets what you see up close.

## Bells & Whistles: Infinite Zoom

I attempted to modify the multiresolution blending method from *Generative Powers of Ten* (Wang et al., 2024) [[1]](#ref-powers-of-ten) to generate a repeating multiresolution image. This works by having several images at different zoom levels. When computing velocities, instead of averaging on overlapping regions, you make a one-step prediction and perform a Laplacian blending with the laplacian pyramids from cut-outs of the corresponding region in the other images. After averaging in the appropriate levels, you render the image with the recursive structure, and from this you convert it back into a velocity with $(\hat{x} - x) / (1 - t)$.

## Part 2: Training a Flow Matching Model

One-step denoising from pure noise can only produce the average digit. Flow matching instead learns a velocity field and integrates it in many small steps as we saw previously. With $$x_0 \sim \mathcal{N}(0, I)$$ and a clean digit $$x_1$$, the interpolant is $$x_t = (1-t)x_0 + t x_1$$, its velocity is $$x_1 - x_0$$, and the UNet $$u_\theta$$ is trained to minimize $$\mathbb{E}\,\lVert (x_1 - x_0) - u_\theta(x_t, t)\rVert^2$$ with $$t \sim U[0, 1]$$.

### Part 2.1: Adding Time Conditioning to the UNet

The UNet needs to know $$t$$. I embed the scalar $$t$$ with two FCBlocks (Linear, GELU, Linear) and use them to scale the decoder features. This is done at the unflattened bottleneck which is multiplied by the first embedding and at the output of the first up block which is multiplied by the second. This embedding by $t$ is needed as the distribution of $x_t$ is dependent on $t$!

### Part 2.2: Training the Time-Conditioned UNet

I trained with $$D = 64$$, batch size 64, and Adam at an initial learning rate of $$10^{-2}$$ for 10 epochs. An ExponentialLR scheduler with $$\gamma = 0.1^{1/10}$$ steps once per epoch, so the learning rate decays to $$10^{-3}$$ by the end.

### Part 2.4: Adding Class-Conditioning to the UNet

To choose which digit to generate, I add two more FCBlocks that embed a one-hot class vector $$c$$. These scale the same decoder features, and the time embeddings now shift them: the bottleneck becomes $$c_1 \cdot \text{unflatten} + t_1$$, and the first up block becomes $$c_2 \cdot \text{up}_1 + t_2$$. During training, the class vector is set to zero with probability $$p_{\text{uncond}} = 0.1$$, so the same network also learns the unconditional velocity needed for classifier-free guidance.

Training uses the same settings as Part 2.2: $$D = 64$$, batch size 64, Adam at $$10^{-2}$$, ExponentialLR with $$\gamma = 0.1^{1/10}$$, and 10 epochs.
